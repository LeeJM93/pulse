## 사용하는 방법

현재 Pulse 저장소를 연 Codex에서 “pulse 구현을 시작해줘” 또는 “pulse 개발을 계속해줘”라고 요청한다.
Codex는 상시 규칙에서 개발 진행 지침과 상태표를 찾아 해당 단계 문서를 읽는다. 단계별 프롬프트를 복사해 넣을 필요가 없다.

`AGENTS.md`는 Codex가 시작할 때 읽는 프로젝트 지침이다. 일반 Markdown 문서는 이 지침의 링크를 따라 필요할 때 읽도록 연결했다.
루트에서 시작하는 작업은 루트 `AGENTS.md`가 Pulse 지침으로 안내한다.
참고: [OpenAI 공식 AGENTS.md 안내](https://learn.chatgpt.com/docs/agent-configuration/agents-md).

## 버전 관리

상위 `stock/`은 일반 폴더이며, `programs/` 아래의 프로그램은 각각 독립 Git 저장소로 관리한다.
Pulse의 저장소 루트는 `programs/pulse/`다. 명세 원본·지침·코드를 이 저장소에서 함께 관리한다.
기본 작업 방식은 `main`과 작업별 브랜치이며, 요청한 변경은 검증 후 논리적인 단위로 로컬 커밋한다.
최초 명세·지침·제외 설정은 `main`의 기준 커밋으로 저장할 수 있다. 이후 구현은 작업 브랜치에서 진행한다.
Push·PR·병합은 요청 또는 사전 허용 범위에 따른다. 실행 데이터·비밀값·생성물은 [.gitignore](.gitignore)로 제외한다.

## 실행 안내

기본 구성은 Python·SQLite·정적 HTML이다. 패키지 이름은 `pulse`, 소스 위치는 `src/pulse/`다.
Phase 0+1에서 인증 없이 실행하는 `pulse demo`와 개발·검증 명령을 구성하고, 실제 실행을 확인한 명령을 이 문서에 추가한다.

현재 실행 가능한 명령은 아직 없다. 실제 API 연결, AI 생성, 웹 게시, 장중 운영은 각각 별도로 검증한다.
