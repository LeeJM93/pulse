# 데이터 대응표

기준: [기능명세](../장중_시황_브리핑_프로그램_기능명세.md) FR-02, FR-05~FR-08, FR-23~FR-28.\
현재는 작성 양식과 조사 항목만 준비했다. 실제 공급자 응답을 확인한 항목은 없다.

## 기록 방법

- 외부 데이터는 **제공 확인 / 직접 계산 / 제공 불가 / 검증 전**으로 분류한다.
- 직접 계산은 입력 공급 경로가 검증됐다는 뜻이 아니다. 계산 구현·자동 테스트·입력 연동 상태를 별도로 기록한다.
- 공식 문서에서 읽은 내용과 실제 계정의 응답·장중 관측으로 확인한 내용을 구분한다.
- API 후보는 명세에서 확인한다. 필드·단위·시각·갱신 주기를 이름만 보고 채우지 않는다.
- 샘플 자료는 `provider=sample` 등으로 출처를 분명히 하고 실제 공급자 검증 근거로 사용하지 않는다.
- 키·토큰·계좌정보를 기록하지 않는다. 실제 응답 근거를 보관한다면 비밀값을 제거하고 공개 산출물에서 제외한다.

## 지표별 기록 양식

API가 여러 개면 API·필드별로 나누어 기록한다. 미확인 항목은 `미확인` 또는 `null`로 남긴다.

| 항목 | 기록할 내용 |
| --- | --- |
| metric | 프로그램에서 사용할 지표 식별자 |
| provider / environment | 공급자와 실서버·모의서버·샘플 구분 |
| source_api / endpoint | 공식 문서에서 확인한 API·경로 |
| response_field | 실제 응답 필드 |
| raw_unit / normalized_unit | 원본 단위와 정규화 단위 |
| conversion_rule | 부호·배수·결측 변환, schema version |
| timestamp_semantics | source_time / observed_at / time_basis |
| update_behavior | 문서상 주기와 실제 장중 갱신 관측 결과 |
| market / venue / universe | 시장·거래소·모집단·포함 종목 기준 |
| aggregation_scope | 개별 계약/전 월물·표준/미니·누적/구간 등 |
| contract / session | 실제 계약과 거래 세션, 필요 시 역할 적용 기간 |
| quality / missing_reason | 품질·누락 사유·허용 시차·제공 제한 |
| verification_status | 제공 확인 / 직접 계산 / 제공 불가 / 검증 전 |
| document_evidence | 공식 문서 URL·확인일·관련 설명 |
| response_evidence | 비밀값을 제거한 실제 응답의 참조·확인 시각 |
| implementation / tests | 구현 위치·자동 테스트·실제 검증 결과 |

## 직접 계산 지표

계산식은 기능명세 7절과 FR-25~FR-27을 따른다.
수익률·상대 강도·거래대금 변화·수급 변화·OI 변화·베이시스·관측 상태를 구현할 때 입력 지표, 실제 비교 시각, 사용한 observation ID, 단위, 품질, 규칙 버전을 함께 기록한다.
