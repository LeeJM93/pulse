# 구현·검증 상태

최종 갱신: 2026-10-03 (Asia/Seoul)\
기준: [기능명세 v0.4](../장중_시황_브리핑_프로그램_기능명세.md)

## 현재 위치

- 개발 지침과 단계별 작업 문서를 준비했다.
- 브랜치·커밋 정책을 채택했다. 변경 작업은 [Git 운영 지침](git_workflow.md)에 따라 검증 후 로컬 커밋한다.
- 기능명세 원본을 Pulse 저장소 루트로 옮겼다. 상위 stock의 기존 파일은 위치 안내만 제공한다.
- 프로그램 코드·환경·테스트·demo는 미착수다.
- **다음 개발 작업: [Phase 0+1](phases/phase-00-01-bootstrap.md)**.
- 첫 작업: 현재 Git 상태와 명세를 읽고 작업 브랜치에서 Python 패키지 `pulse`, 개발 도구, 샘플 실행 경로를 구성한다.
- 실제 현물·선물 API, AI 생성, 웹 게시, 장중 운영은 미검증이다. 외부 계정·인증·권한의 설정 상태도 아직 확인하지 않았다.
- 문서 준비 완료를 기능 구현 완료로 계산하지 않는다.

## 상태 기록 규칙

| 구분 | 사용 값과 의미 |
| --- | --- |
| 구현 | 미착수 / 진행 중 / 구현 완료 |
| 자동 검증 | 미실행 / 통과 / 실패 / 부분 통과 |
| 실제 연동·운영 검증 | 미검증 / 확인 / 실패 / 대상 아님 |
| 진행 제약 | 없음 / 설정 상태 미확인 / 미설정 / 권한 부족 / 제공 불가 / 차단 사유 |

구현·자동 테스트·실제 검증은 서로 다른 열에 기록한다.
`implemented`, `automated test passed`, `integration verified`, `operationally verified`를 혼용하지 않는다.
실제 연동은 검증한 항목과 환경에 한해 “확인”으로 바꾼다.
미설정·제공 불가·권한 부족은 확인한 근거가 있을 때만 기록한다.
복합 AC의 일부만 통과했다면 전체 통과로 표시하지 말고 남은 조건을 쓴다.

## 문서 준비 확인 — 2026-10-03

- 마크다운 문서 14개와 상대 링크 72개를 확인했다.
- AC-01~AC-36을 모두 상태표에 연결했고 FR·AC 참조가 명세에 존재하는지 확인했다.
- 기능명세 원문의 SHA-256을 작성 전후 비교해 변경하지 않았음을 확인했다.
- 코드·자동 테스트·실제 연동은 아직 수행하지 않았다. 현재 검증은 문서의 구조와 참조에 한정된다.
- Git 상태 조회는 이 Mac의 Xcode 라이선스 미동의로 실행되지 않았다. 새로 작성한 파일을 직접 읽어 검토했다.

## Git 지침 적용 — 2026-10-03

- 범위: 작업 브랜치·로컬 커밋·기존 변경 보존·원격 작업 조건을 상시 규칙과 개발 절차에 연결했다.
- 저장소: Pulse는 독립 Git 저장소다. 최초 기준 문서·설정은 `main`에 저장하고 다음 구현은 작업 브랜치에서 진행한다.
- 명세: 원본을 Pulse 루트로 이동해 v0.4로 갱신했다. 경로·문서 관리 안내만 수정했으며 FR 28개와 AC 36개의 원문은 동일하다.
- 검증: Pulse Markdown 15개와 저장소 내부 링크 82개, 상위 폴더의 진입 링크를 확인했다. 제외/포함 설정 16개 사례도 통과했다.
- 환경: 현재 Git 조회는 정상 실행된다. 앞선 문서 준비 당시의 Xcode 라이선스 오류는 현재의 차단 사유가 아니다.
- 커밋 범위: Pulse 안의 명세·지침·README·단계 문서·`.gitignore`. 커밋 ID와 최종 Git 상태는 완료 보고에서 전달한다.
- 저장소 밖 변경: 상위 stock의 `AGENTS.md`와 기존 명세 위치 안내를 갱신했다. 두 파일은 상위 저장소의 변경으로 남기고 Pulse 커밋에 포함하지 않는다.
- 프로그램 구현·코드 품질 도구·실제 외부 연동 검증은 미착수다. 다음 작업은 Phase 0+1이다.
- Push·PR·병합은 수행하지 않는다. 원격 저장소는 아직 설정되지 않았다.
